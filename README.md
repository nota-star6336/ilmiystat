# IlmiyStat demo

This repository contains a public demo/source preview of the IlmiyStat web interface.

Included:
- static frontend pages and client-side assets;
- public visual assets and screenshots;
- UI structure for evaluation and product review.

Not included:
- production backend implementation;
- database dumps or real data;
- uploaded user files;
- API keys, local configuration, secrets;
- private deployment scripts and internal project materials.

The full working system is maintained privately. This public version is provided
only for review of the product interface and MVP scope.
